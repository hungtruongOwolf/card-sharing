# raw/ — immutable sources

Drop anything here: chat summaries, research, screenshots, PDFs, links.
Never edit a file after it's saved — add a new dated file instead.
Then run `/memory ingest <file>` so the agent compiles it into `wiki/`.

- `discussions/` — idea sessions, meetings, decisions talked through with the EM
- `research/` — web research, benchmarks, competitor notes (always keep source URLs)
- `assets/` — images, sketches, mockups, PDFs
